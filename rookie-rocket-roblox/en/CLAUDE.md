# NASA Space Adventure — project instructions

A Roblox Studio map inspired by the Kennedy Space Center. Route: reception (museum/planetarium in the east wing) → Corridor 1 → Launch Control Center → Corridor 2 → VAB with SLS + Mobile Launcher + crawler → pedestrian exit → observation area for pad 39B (crawler route alongside).

## References

- **Current spec:** `spec-v3.md` (map construction, §1–§15) + §16 (what is left for later). `spec.md` applies to whatever v3 does not change (coordinates of the reception, corridors, museum). `spec-ultimate.md` is historical.
- **Missions (Rookie Rocket):** `docs/rookie-rocket-spec.md` (Mercury and ISS missions, co-op 1–4, weight, stars, DataStore, Album) and `docs/rookie-contrato.md` (part names × scripts). Texts in English. It replaces the seated mission from the old Phase 15.
- **Scope (spec-v3 §16.10):** physical construction, dimensional validation, circulation and visual quality only. Do not implement transport, synchronization, a dynamic exclusion zone, a working room, liftoff, DataStore or badges until there is a spec for the next phase.
- **Implementation notes:** `IMPLEMENTATION.md` (state of each step, validations, pending items). Update it with every change.

To rebuild:

1. Serve `build/` in the background: `python3 -m http.server 8765 --bind 127.0.0.1` (stop it when done).
2. Phases 1 and 2 (standalone): load and run in Edit (`loadstring(HttpService:GetAsync(...))()`).
3. `build/run_in_studio.luau`: runs Phases 3–6, 8–14 and 16–24 in order, passing `lib.luau`.

Generator rules:

- Each phase uses `lib.builder(N)`: every part gets `BuildPhase = N`, and the phase starts with `B.clear(Map)`, so re-running is idempotent.
- Phase 9 moves parts from Phases 3, 5 and 8 into the transport assembly. To redo any of them, run the whole runner (Phase 3 onward), not the single phase.
- The generators' local variable is still `Map`, but the root is `NASAComplex`.
- Coordinates: X width, Y height, Z player progression; central axis X = 0; floors with their top at Y 0 (Baseplate at Y −1).
- Sign and prompt texts in English; fonts through `FontFace` (Montserrat; `Code` on telemetry). Do not use `Enum.Font.Gotham*` (removed).
- Everything that moves lives in `TransportSystem.TransportAssembly`; whatever follows the assembly uses relative references (`ZoneOffset`, `TargetRef`), never absolute coordinates.

## Rojo, VS Code and GitHub

- **Rojo** (pinned in `rokit.toml`) syncs **all scripts** (`default.project.json`): `build/rookie/` (Rookie Rocket missions), `build/guide/` (guides and arrow), `build/museum/` (museum), `build/systems/server` → `ServerScriptService.Map_Systems` (AutomaticDoors, CrewAccess) and `build/systems/client` → `StarterPlayerScripts.MapClient` (PlanetOrbits, CrewClient).
- With Rojo connected, the folders carry the `RojoManaged` attribute and the phases (6, 8, 18, 21) do not reinstall the scripts; without Rojo, `lib.installSystemScript` downloads from `build/systems/` over HTTP.
- New scripts go in files in those folders, never as text embedded in a generator.
- Only the map (parts) still goes through the HTTP server. Do not use `rojo build` (the map is not in the project).
- Installation and usage guide: `ROJO.md`. Remote: `git@github.com:tulioamaral123/roockie-rocket.git`.

## Saving tokens (working standard)

- Script change: edit only the `.luau` file; Rojo carries it to Studio. Do not open Studio through the MCP for that.
- Do not use the Studio MCP (screenshot, `execute_luau`, `inspect_instance`, playtest) unless the user asks. They test and paste the error from the Output.
- Read only the needed excerpt (`grep -n` and then `sed -n` / `Read` with an offset), never whole large files (specs, generators).
- Do not re-read a file you just edited; short answers; do not repeat the plan in the text.
- `IMPLEMENTATION.md`: only one short line per change, at the end of the file.

## Validations that must keep passing

- **Assembly envelope:** X −34..34, Y 0..133 in the VAB; back gate 80 × 140 (vertical clearance 7, lateral ≥ 6).
- **Route sweep** (part by part, translated boxes): arrival of the assembly from Z 265 to Z 700, crawler retreat from 700 to 620 and sideways to (90, 0, 620) — 0 intersections, except the back gate leaves.
- **View of the SLS** from the front gate (eye at (0, 4.5, 211)): nothing fixed between the visitor and the rocket.
- Route playtest: reception → museum (east wing) → Corridor 1 → LCC → Corridor 2 → VAB → suit-up room → stairs → elevator → Orion → pedestrian exit → observation area. Console without errors.
- Rookie Rocket: kiosk in the LCC → Board → Preparation (80 kg fails on the pad) → Tasks 1–3 → result with the equation and stars → Album; Retry task / Restart mission; the same on the ISS (EVA in Task 2).
